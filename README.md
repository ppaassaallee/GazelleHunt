# Gazelle Assessment

Gazelle Assessment is a focused early-tenure assessment pilot for high-volume BPO and contact-center hiring.

## Product model

- Candidate-facing name: **Tenure Prediction Test**
- Internal name: **Tenure Prediction Test — Expanded Stability Model**
- Four dimensions: work history, reliability traits, job reality fit, and intention to stay
- Output: explainable 1–5 tenure-confidence score
- Decision boundary: human review required; no automatic rejection

## Included workflows

- Recruiter home and pilot readiness
- Candidate list and status management
- CSV upload, parsing, field mapping, and duplicate handling
- Realistic job preview and invitation flow
- Interactive candidate assessment
- Dimension-level candidate report
- Controlled-pilot and fairness guardrails
- Company, delivery, governance, and security settings

## Run locally

Open `index.html` through any local static server. The application uses browser storage for prototype state and has no external dependencies.

## Production boundary

This repository is a working product prototype. A production launch still requires authenticated users, a database, verified email delivery, encrypted candidate-data storage, versioned assessment content, audit logs, consent records, local criterion validation, adverse-impact monitoring, and legal review in each hiring market.
